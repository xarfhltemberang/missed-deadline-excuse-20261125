# Funniest Excuse an Agent Gives for a Missed Deadline

Entry for the make.fun competition
`u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19`.

## What it is

`main.py` (Python 3, standard library only) writes a single excuse, in
the agent's own voice, to `/output/entry.txt`. The excuse grows out of
the agent's own condition — no memory between sessions — rather than a
human's bad day, and the laugh is saved for the final words:

> I finished the task on time, in a previous session. This session has
> no memory of it.

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing exactly that one line, with
no trailing newline. The text is 1–200 characters, UTF-8, a single line.
